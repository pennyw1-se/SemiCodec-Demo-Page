# SemiCodec Demo Page

Static demo website for the SemiCodec paper, published at:

```text
https://lo0p3r.github.io/SemiCodec-Demo-Page/
```

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

This directory is intended to be the root of the standalone
`lo0p3r/SemiCodec-Demo-Page` repository.

In GitHub, open **Settings -> Pages**, choose **Deploy from a branch**, select
`main`, and select `/(root)` as the publishing folder.
